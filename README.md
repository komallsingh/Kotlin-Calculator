# 🧮 Kotlin Calculator App

![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=for-the-badge&logo=kotlin&logoColor=white)
![Android](https://img.shields.io/badge/Android-3DDC84?style=for-the-badge&logo=android&logoColor=white)

A simple and clean **Android Calculator Application** developed using **Kotlin** and **XML**.  
This project highlights the separation of UI design and application logic in Android development.

---

## 🚀 Features

- ➕ Addition  
- ➖ Subtraction  
- ✖️ Multiplication  
- ➗ Division  
- 🧹 Clear / Reset input  
- 📱 Simple and user-friendly interface  

---

## 🛠 Tech Stack

- **Kotlin** – Application logic  
- **XML** – UI design  
- **Android Studio**
- **Android SDK**

---

## 🧠 App Overview

- XML layouts handle the **visual structure**
- Kotlin manages **user interactions and calculations**
- Button click events process user input
- Results are displayed instantly
